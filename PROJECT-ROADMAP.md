# Project roadmap — charter, acceptance criteria and status

> **What this is:** the charter of this repository as a portfolio and learning project, the acceptance criteria it is held to, what is done and verified, and what remains. **For:** the owner and anyone who wants to know how complete the repository really is. Status as of **2026-10-17**.

## Charter

| | |
|---|---|
| **Purpose** | **Prove** practical IT business analysis capability, **demonstrate** it with a working example, and **teach** the owner to understand and defend every artefact |
| **Case** | Multimodal shipment visibility and exception management for Tidewell Logistics — a **fictional** short-sea and door-to-door operator |
| **Audiences** | recruiters and hiring managers (5 minutes), analysts and developers (deep dive), the owner (learning) |
| **Out of scope** | any real company's internal information; real stakeholders; deployment to a real organisation; paid services |
| **Principles** | documents are the source of truth; every claim labelled proposed / simulated / measured; complement the TMS rather than replace it; small and understandable over impressive |

## How to publish (already set up)

The repository is public and GitHub Pages deploys on every push to `main` ([pages workflow](.github/workflows/pages.yml)): the static site in `site/` plus the control tower built into `site/control-tower/` and the learning page reading `site/learning/learning-data.json`. CI ([workflow](.github/workflows/ci.yml)) must be green before sharing a link.
