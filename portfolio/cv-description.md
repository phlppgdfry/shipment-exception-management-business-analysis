## English — LinkedIn "Projects" entry

Independent portfolio case for a fictional short-sea and door-to-door operator whose customers heard about delays at the gate. I reframed three conflicting requests as one problem (missing rules for what counts as late and who tells the customer), compared four options in a business case and recommended a six-week pilot with a control group. The case includes stakeholder analysis, a simulated event storming, BPMN 2.0 models, requirements with traceability, rules expressed as executable examples, a prioritised backlog, UX design, an OpenAPI contract, acceptance testing and production readiness. A browser demo (Next.js, TypeScript) runs the same rules; unit, contract, end-to-end and accessibility tests run in CI. Workshops, stakeholders and delivery are simulated; built with AI assistance.
