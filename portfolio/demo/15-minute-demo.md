# 15-minute case presentation

For a case interview. Use the [interview deck](../presentation/interview-deck.pptx) for the first five minutes, then the demo, then the evidence.

| Time | Part | Open | Point to make |
|---|---|---|---|
| 0–2 | Problem | deck slides 1–2 | three requests, one root cause |
| 2–4 | Framing | [business case](../../docs/01-opportunity/options-and-business-case.md) | options on agreed weights; riskiest assumption; pilot with stage gate |
| 4–6 | Workshop | [dialogue](../../docs/03-workshops/workshop-dialogue.md) | positions → needs → severity; PO decides |
| 6–9 | Demo | [control tower](https://phlppgdfry.github.io/shipment-exception-management-business-analysis/control-tower/) — [2-minute script](2-minute-demo.md), plus the duplicate and out-of-order buttons in step 3 | rules → owner → customer; integration robustness |
| 9–11 | Precision | [rules](../../docs/05-requirements/exception-rules.md), [DMN](../../docs/05-requirements/dmn/exception-decisions.dmn), [TO-BE](../../docs/04-process/to-be.md) | boundaries, row order, timer events, D-09 found by building |
| 11–13 | Delivery | [BAT log](../../docs/09-acceptance/bat-log.md), [go/no-go](../../docs/10-go-live/release-readiness.md), [change & adoption](../../docs/10-go-live/change-and-adoption.md) | DEF-04 (own mistake); used, not just installed |
| 13–15 | Honesty and questions | [EVIDENCE.md](../../EVIDENCE.md), [role matrix](../role-requirement-matrix.md) | what is simulated; what I would validate first; questions for them |

**If they interrupt with "how would you do this here?"** — switch to the BA loop: understand → explore → analyse → weigh → specify → communicate ([module 9](../../learning/modules/09-case-exercises/README.md)).
