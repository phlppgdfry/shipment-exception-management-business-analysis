# Mijn werk

Hier zet je **je eigen** antwoorden op de begeleide oefeningen, uitdagingen en competentietaken — één bestand per module of taak, bijvoorbeeld `module-01.md` of `task-03.md`.

Waarom dit belangrijk is: deze repository is grotendeels met AI-hulp gemaakt. Je toont pas competentie met wat je **zelf** schrijft, zonder de modeluitwerking open te hebben, en daarna eerlijk vergelijkt. De [voortgangstracker](../progress-tracker.md) verwijst naar deze bestanden als bewijs.

Template:

```markdown
# Module NN — <titel>
Datum: JJJJ-MM-DD · Tijd besteed: … · Hulpmiddelen gebruikt: (geen / docs / AI — wees eerlijk)

## Begeleide oefening
…

## Zelfstandige uitdaging
…

## Vergelijking met de modeluitwerking
Wat had ik goed? Wat miste ik? Wat zou ik nu anders doen?

## Score (rubric)
…/10
```
