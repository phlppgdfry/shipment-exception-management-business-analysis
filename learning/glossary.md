## Analyse en methode

| Term | Betekenis | Module |
|---|---|---|
| Acceptatiecriterium (acceptance criterion, AC) | voorwaarde waaraan een story moet voldoen om af te zijn | 3 |
| AS-IS / TO-BE | huidige / gewenste situatie | 2 |
| Aanname (assumption) | iets waar je op bouwt alsof het waar is, met een manier om het te controleren | 1 |
| Baseline | gemeten beginwaarde van een indicator | 1 |
| Bedrijfsregel (business rule) | beleid dat bepaalt wat er gebeurt (ER-xx) | 3 |
| Beslistabel (decision table) | voorwaarden en uitkomsten per regel | 3 |
| Business case | onderbouwing met opties, kosten, baten, risico's en aanbeveling | 1 |
| Business need | wat de organisatie nodig heeft, los van de oplossing | 1 |
| Capability map | overzicht van wat een organisatie doet, los van wie of welk systeem | 1 |
| Constraint (beperking) | voorwaarde die binnen de release niet onderhandelbaar is | 1 |
| Dependency (afhankelijkheid) | werk of beslissing van een ander dat je nodig hebt | 4 |
| Discovery | fase waarin je probleem en context leert kennen | 1 |
| Event storming | workshop waarin een domein als tijdlijn van gebeurtenissen wordt opgebouwd | 1, 2 |
| Gap-analyse | verschil tussen AS-IS en TO-BE, met type verandering | 2 |
| Gherkin | Given/When/Then-taal voor acceptatiecriteria | 3 |
| Hotspot | rode sticker: onenigheid of onwetendheid die een beslissing vraagt | 1 |
| Impactanalyse | wat een wijziging raakt: artefacten, data, mensen, KPI's | 9 |
| KPI | meetbare indicator met doel en eigenaar | 1 |
| MoSCoW | Must, Should, Could, Won't (this time) | 3, 4 |
| Persona | samengestelde gebruiker op basis van onderzoek | 5 |
| RACI | Responsible, Accountable, Consulted, Informed | 1 |
| Root cause (grondoorzaak) | onderliggende oorzaak, bv. via 5 whys | 1 |
| Specification by example | specificeren met voorbeelden die ook tests zijn | 3 |
| Stakeholder | wie geraakt wordt of invloed heeft | 1 |
| SWOT | sterktes, zwaktes, kansen, bedreigingen | 1 |
| Traceability | koppeling van doel tot test en KPI | 3 |
| User story | rol, wens, reden ("As a… I want… so that…") | 3 |
| WSJF | Weighted Shortest Job First: cost of delay ÷ size | 4 |
